# Asset Attributions

## Runtime Assets

Neon Relay Stage 1 uses no external art, models, textures, fonts, music, or sound effects. All visible game content is procedural Three.js geometry, generated canvas output, and CSS authored for this project.

- Vite, MIT License: <https://github.com/vitejs/vite/blob/main/LICENSE>
- TypeScript, Apache License 2.0: <https://github.com/microsoft/TypeScript/blob/main/LICENSE.txt>
- Playwright, Apache License 2.0: <https://github.com/microsoft/playwright/blob/main/LICENSE>

Future externally generated or sourced assets must be added here with creator/provider, source URL or task identifier, license, modifications, and runtime file path before integration is considered complete.
